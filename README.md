# Factorio Module Calculator

Lists what combinations of modules can be used to reach a desired percentage
buff. Useful for situations where item production rates must be exact values
rather than approximations.

Quality allows a wider range of modules to be chosen, allowing for more precise
percentages.

### Dependencies
